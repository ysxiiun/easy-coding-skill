# 短期记忆模板

> 本模板用于 `.easy-coding/memory/short/` 下的单次任务记忆。
> 文件名规则：`{序号}_{日期}_{智能命名}.md`

## 任务概述

- 任务类型：{新功能 / Bug 修复 / 重构 / 性能优化 / 前端设计实现 / 文档或流程调整}
- 目标：{本次真正解决的问题}
- 范围：{本次实际涉及的模块、页面、接口或文件}

## 技术方案摘要

- 方案标题：{ANALYSIS 阶段确认的方案标题}
- 核心改法：{一句话概括最终实施方式}
- 关键约束：{编码、兼容、接口、Spec、Prototype 或用户指定约束；无则写“无”}

## 变更内容

| 文件 / 模块 | 变更类型 | 说明 |
|---|---|---|
| {路径或模块} | {新增 / 修改 / 删除} | {关键变更说明} |

## 验证结果

- 自动化验证：{测试 / 构建 / 静态检查命令与结果；未执行则说明原因}
- 人工验收：{已检查的关键行为；无则写“无”}
- 未验证项：{无 / 说明缺失环境、数据、权限或接口契约}

## 问题与解决方案

- {遇到的问题及处理方式；无则写“无”}

- 后续：{后续关联任务；无则写“无”}
