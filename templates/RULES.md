# 编码规范

## 命名规范【强制】

- 类名：UpperCamelCase
- 方法/变量：lowerCamelCase
- 常量：全大写下划线分隔
- 包名：全小写
- 禁止拼音命名

## 代码结构【强制】

- 方法单一职责，不超过80行
- 方法参数不超过5个
- 禁止循环内数据库查询
- 禁止魔法值

## 注释规范【强制】

- public 方法必须有 Javadoc
- 类级别必须有 Javadoc
- 修改他人代码需注明修改人和原因

## 异常处理【强制】

- 禁止空 catch 块
- 禁止直接捕获 Exception
- 对外接口必须捕获所有异常
- 日志记录必须打印完整堆栈

## 日志规范【强制】

- 使用 @Slf4j
- 生产环境禁止 DEBUG
- 日志必须包含业务标识
- 禁止打印敏感信息
