# 记忆兼容迁移流程

> 本文件由 `SKILL.md` 在 INIT 阶段发现旧版记忆结构并获得用户确认后加载执行。
> 迁移范围仅限 `.easy-coding/memory/`，不得修改业务代码、Spec、Prototype 或其他项目文件。

---

## 进入条件

满足任一条件时，`SKILL.md` 必须先在 `[阶段：INIT]` 提示用户确认；用户确认后才进入 `legacy_memory_migration`：

- `.easy-coding/memory/long/MEMORY.md` 存在但缺少 `memory_schema: 2`
- `.easy-coding/memory/long/BUSINESS.md` 缺失
- `.easy-coding/memory/long/TECHNICAL.md` 缺失
- `.easy-coding/memory/short/*.md` 存在缺少 frontmatter 或 `memory_schema != 2` 的旧版短期记忆
- `MEMORY.md` 仍是旧版长期正文，而非索引导航

---

## 迁移原则

1. 未获得用户明确确认前，不得执行迁移；确认提示和用户确认均发生在 `INIT` 阶段。
2. 旧版长期记忆不得丢弃，必须迁移到 `BUSINESS.md`、`TECHNICAL.md`、新索引或已淘汰记录中。
3. 旧版短期记忆不先转换为新版短期模板；触发旧版迁移时，所有旧版短期记忆一次性参与沉淀。
4. 迁移成功后，删除全部已处理的旧版短期记忆文件；迁移完成后，新生成的 schema 2 短期记忆才按滑动窗口运行。
5. 若新旧内容冲突，优先当前代码和用户最新表达；旧内容进入对应文件的“已淘汰记录”。
6. 迁移完成后，可按 `flow/memory-retirement.md` 对迁移出的主题执行一次定向淘汰检查；仍不得做无边界全仓扫描。
7. 迁移过程必须输出审计摘要，说明识别、迁移、删除和未沉淀内容。

---

## 旧版长期记忆拆分规则

读取旧版 `.easy-coding/memory/long/MEMORY.md` 后按内容拆分：

- 进入 `BUSINESS.md`
  - 业务规则
  - 字段语义
  - 业务流程
  - 状态流转
  - 上下游契约
  - 业务排障经验
- 进入 `TECHNICAL.md`
  - 架构决策
  - 接口决策
  - 技术选型
  - 工程规则
  - 实现模式
  - 易错点与修复策略
  - 验证、发布与安装经验
- 进入已淘汰记录
  - 明确过期、被当前代码替代、与用户最新表达冲突的内容

拆分完成后，重写 `MEMORY.md` 为 `memory_schema: 2` 索引，只保留主题、类型、关键词、详情文件、状态、最近更新和来源。

---

## 旧版短期记忆一次性沉淀规则

读取 `.easy-coding/memory/short/*.md`：

- 缺少 frontmatter，或 frontmatter 中 `memory_schema != 2` 的短期文件，都视为旧版短期记忆
- 不要求旧版短期记忆先补齐新版 frontmatter
- 触发 `legacy_memory_migration` 时，所有旧版短期记忆一次性参与沉淀，成功后短期目录不留下旧版文件
- 按统一排序规则稳定处理旧短期：
  - 优先按 frontmatter `date` 升序
  - 缺少 `date`、`date` 无法可靠解析或 `date` 相同时，降级按文件名前缀序号升序
  - 仍无法区分时，按文件名升序稳定排序
- 旧版短期数量 <10 条时也参与本次迁移沉淀，避免缺少 frontmatter 的旧文件反复触发迁移
- 对全部旧版短期按正文内容分拣业务候选、技术候选和不沉淀内容
- 写入 `BUSINESS.md` / `TECHNICAL.md`
- 更新 `MEMORY.md` 索引来源
- 成功后删除全部已处理的旧版短期文件；后续新生成的 schema 2 短期记忆再按滑动窗口规则运行

不进入长期记忆的内容：

- 普通文件修改清单
- 单次任务流水
- 临时日志、临时订单号、一次性 mock 数据
- 没有复用价值的实现细节

---

## 迁移审计输出

```markdown
[阶段：INIT]

### 旧版记忆迁移完成

- 识别到的旧版文件：{文件列表}
- 迁移出的业务主题：{主题列表；无则写“无”}
- 迁移出的技术主题：{主题列表；无则写“无”}
- 已删除的旧版短期记忆：{文件列表；无则写“无”}
- 未沉淀内容及原因：{摘要；无则写“无”}
- 冲突处理：{旧内容淘汰 / 新内容生效 / 无冲突}
- 淘汰检查：{删除 / 合并 / 淘汰摘要；未执行则写“未执行：无冲突或无重复主题”}

将自动按新版记忆结构继续进入 ANALYSIS。
```

---

## 返回 SKILL.md

迁移完成后，返回 `SKILL.md` 的输入发现与背景数据加载规则，按新版三文件记忆结构继续执行。
